# Contributing

Verichron Epoch is proprietary software owned by Verichron Inc. The source is
public so it can be read, but it is not an open-source project (see
[LICENSE](LICENSE)).

**Outside contributions are not accepted.** Pull requests, patches and code
suggestions from outside Verichron Inc. are closed without review, because
there is not yet a contributor agreement under which they could be accepted.
This will be revisited if one is put in place.

**Reporting a problem is welcome.** Open an issue describing it. Never include
case data, real device identifiers, backups, extraction output or reports in an
issue, comment or attachment: this repository is public.
